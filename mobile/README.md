# 行迹 Android 本地版

这是独立 Android 应用，不需要启动电脑、不连接行迹网站，也不包含现有行程、网站密码或预设 API Key。桌面版和在线版没有被改动。

## 1.4.0 简化添加

添加航班默认只显示航班号和日期，其余字段可在原确认窗口展开填写，或保存后修改。只填这两项即可保存，仍以航班号与日期去重；未补齐机场的记录不绘制航线、不计入航线排行榜。AI 已识别或编辑时已有的其他信息会展开供核对。

按用户要求移除两处新增的常驻填写说明，不改其他布局。只在点击保存而航班号或日期缺失时弹出对应提醒，不保存未填全的草稿。使用原签名，可覆盖升级保留数据。

## 1.3.0 全球同等级离线地图

全球国家轮廓、省级边界、主要道路、湖泊、城市区域和城市点均使用 Natural Earth 10m（约 1:1000 万）数据，不再只对东亚打包细节。全球采用同样的简化标准，道路容差 0.003 度，其余几何 0.01 度；坐标保留最多 5 位小数。实际地图 JSON 为 35,030,348 bytes（约 35 MB），gzip 为 9,179,172 bytes，低于 100 MB 上限。最终安装包体积见验收记录。

共 258 个国家／地区要素、4,596 个行政区要素、56,600 条道路要素、1,355 个湖泊要素、11,878 个城市区域要素及 7,340 个中文城市点。中国 34 个省会、首府、直辖市及港澳台城市补录仍保留。此处“同等级细节”指相同来源比例尺和处理标准，不承诺各地源数据同样完整，也不包含街道级、门牌或导航数据。

已删除地图底部的常规说明文字；只有机场无法定位时保留校准入口。全球几何使用空间网格筛选当前视口，分批建立索引并释放离开视口的图层，减少大数据量的平移开销。默认离线模式与联网细节开关不变。

1.3.0 使用相同包名和签名，可直接覆盖安装 1.2.0，保留现有记录和 API 设置，无需卸载。构建源文件缓存按 source commit 存在 `toolchain/offline-map-source-cache`，不会进入安装包。

## 1.2.0 内置离线地图

安装包包含 Natural Earth 公共领域地图数据，无需启动时联网下载：全球国家轮廓、东亚省级边界、主要道路、湖泊、城市区域及中文城市名；覆盖中国省会、自治区首府、直辖市和港澳台，以及东亚其他国家主要城市。默认仅使用离线底图，可以在地图右上角启用联网细节；联网瓦片不可用时仍保留离线底图。模式在本机记忆，不影响航班、机场坐标、地图缩放与统计。

**精度边界：** 离线地图用于国家、地区和城市概览，来源比例尺约 1:1000 万至 1:5000 万；城市坐标是近似中心点，不是街道、门牌或导航数据。放大后不会自动产生更多离线街道。机场节点仍使用原有机场目录坐标，而不是城市中心。边界按来源数据保留，仅为地图示意，并非权威行政边界。

数据许可、源地址与覆盖计数见 `offline-map/data/manifest.json`；需要更新源数据时运行 `node scripts/build-offline-map.mjs`，再重新打包。构建不批量下载公共 OSM 瓦片；当前详细在线底图仍遵守供应方瓦片政策。

1.2.0 继续使用原包名和签名，可覆盖安装 1.1.0，保留现有记录和 API 设置；无需卸载或清除数据。

## 1.1.0 界面更新

首页只展示航班地图，底部四栏分别为地图、添加行程、历史行程、设置。历史行程页可切换统计排行榜与具体航班列表；API 设置、JSON 导入及完整备份导出统一放在设置页。状态栏与页面使用同一浅色底，并显示深色系统图标；启动图标改为深蓝圆角底的白色右上箭头。

新版使用同一包名与签名，可以直接覆盖安装 1.0.0，无需卸载，保留现有本机记录和 API 设置。1.1.0 已在 MI14 真机确认状态栏、导航、地图、历史记录与设置入口。

## 安装与使用

将交付的 APK 发送到手机，点击安装；系统提示时允许当前文件管理器安装应用。系统最低为 Android 7.0，建议使用较新的 Android 和最新版 Android System WebView。

第一次打开为空列表。点击「API 设置」填写服务商的 HTTPS 地址、模型名及自己的 API Key；接口需兼容 Chat Completions，识别截图的模型必须支持图片。可以不配置 API，使用手动填写或简单文字本地规则。

识别结果需要先核对、修改，再确认保存。重复判断使用航班号与预计出发日期。支持航班详情、航空公司标志、机场航线图、机场出发/到达列表和历史统计；737 的细分型合并，A320/A321、737NG/MAX 分开统计。

记录和设置以 JSON 文件保存在 Android 应用私有目录，不使用数据库。API Key 依照原项目要求不额外加密，仅存本机，不进入备份。Android 自动云备份与设备迁移均已禁用。

「导出完整备份」通过系统文件选择器保存行程、地点校准和飞机资料缓存，不包含 API Key。「导入备份」支持本应用完整备份、桌面版 version 2 行程导出与 version 1 完整备份；确认后合并，重复航班略过。**卸载应用或清除应用数据会删除记录，请提前导出备份。** 同签名覆盖安装保留记录。

## 联网边界

已保存的记录、编辑、去重、统计、机场目录和内置底图可以离线使用。AI 识别发送当次文本和所选图片到你设置的 API；可选地图街道细节、飞机资料和联网照片需要网络。在线瓦片遵循 Android WebView 的 HTTP 缓存策略；它们不作为内置离线数据批量下载。飞机资料按注册号（兼容连字符）从 Airport-Data / Planespotters 查询并缓存，照片显示作者。上游暂不可用时保留已有记录，不编造资料。

## 重新构建

本目录为独立 pnpm 项目：安装依赖后执行 `pnpm test`、`pnpm run build:web`、`pnpm exec cap sync android`，在 Android Studio 中打开 `android`，或使用 `build-android.ps1`。需要 Node 22+、JDK 21、Android SDK 36、Build Tools 35 和 Gradle 8.14.3。

`setup-signing.mjs` 生成/保留个人签名文件。**保留本机 `signing` 文件夹，否则后续 APK 无法覆盖安装。** 不要分享其中的私钥，也不要把 `toolchain`、`node_modules`、私有数据或网站配置打包分发。

## 验证范围

自动化测试覆盖本地 API、确认前不保存、去重、并发写入、飞机缓存、备份排除密钥和导入回滚。手机尺寸浏览器检查覆盖添加、刷新后持久保存、API 识别草稿、重复阻止、三项排行榜与小屏排版。浏览器检查不等于 Android 真机验收；实际 APK 的系统文件选择器、网络与照片仍需真机确认。
